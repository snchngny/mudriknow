# 共有マニュアル台帳

catalog.jsonは公開資料への案内。アプリはGitHub Rawからログインなしで取得し、対象アプリ・OSに一致する資料を端末へ保存する。資料本文は再配布しない

項目はappName、platform（windows/macos/all）、title、url（公開HTTPS）、documentVersion（不明なら空）、language、license。個人情報・認証用URL・ファイルパス・画面・会話は投稿しない。資料の版とアプリの版を混同しない

匿名受付の設定はworker/README.mdを参照。自動検証・重複排除後に台帳を更新する。投稿者のGitHubアカウントは不要。問題のある登録は運営が削除できる
